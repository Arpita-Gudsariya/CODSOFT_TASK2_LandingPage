# Pixelora — Digital Studio Landing Page

Pixelora is a modern and responsive landing page created as part of my CODSOFT Level 1 Task 2.

The project focuses on creating a clean, visually appealing digital studio website using HTML and CSS.

## 🚀 Live Demo

[View Live Website] 
https://arpita-gudsariya.github.io/CODSOFT_TASK2_LandingPage/

## 📌 Features

- Responsive design for desktop and mobile
- Modern navigation bar
- Hero section with call-to-action buttons
- Services section
- About section
- Work/Projects section
- Contact section with form
- Responsive footer
- Smooth scrolling navigation
- Hover effects and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Design
- CSS Grid
- CSS Flexbox

🎯 Project Objective

The objective of this project was to practice HTML and CSS by creating a professional landing page with proper sections, layouts, spacing, colors, and responsive design.

📱 Responsive Design

The website is designed to adapt to different screen sizes, including desktop, tablet, and mobile devices.
